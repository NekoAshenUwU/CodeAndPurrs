- **码上撸猫 / CodeAndPurrs**：给 AI 伴侣「予予」的可爱风聊天网页 app。线上 **https://nekopurrs.uk** 。

- 技术栈：前端 **React + Vite**（`src/`）；后端**零依赖 Node 代理** `server/proxy.mjs`（把各家 API key 藏服务端，前端只跟 `/api/chat` 说话）。
- 部署：**DigitalOcean VPS**，IP `178.128.127.91`，root，路径 `/var/www/codeandpurrs`。
- 隐私：`.env` 和 `server/data/` 都在 `.gitignore` 里，**永不入库**（日记等私密数据只在 VPS 本地）。

### 部署命令（VPS 上，一整段）
```
cd /var/www/codeandpurrs && git pull origin claude/codepurrs-progress-docs-7tcqk2 && npm run build && pkill -f proxy.mjs; nohup node --env-file=.env server/proxy.mjs > proxy.log 2>&1 & sleep 2 && head -3 proxy.log
```
> 注：前端改动要 `npm run build`；后端改动要 `pkill + nohup` 重启。`proxy.log` 第一行会打印各 provider 状态。

## 5. 关键经验 / 坑（务必先读，别重复踩）

### 思考链
- 无头 CC 下：**Opus 4.6 默认显示思考摘要**（前端能看到云朵）；**4.7 / 4.8 默认隐藏**（Anthropic 把 `display` 默认改成 `omitted`，**Claude Code CLI 没有开关**能改成 summarized）。
- 结论：**想看思考链 → 用「CC · Opus 4.6」**；要最强脑子 → 4.8（看不到思考）。
- 朋友的 CC 有思考链，是因为他用**交互式终端**（TUI 自己渲染），我们是**无头后端**，只能吃流里给的。
- 真要 4.7/4.8 也可见思考：只有走**付费 API 版**（API 能传 `display:"summarized"`，已在 `callAnthropic` 里开了 `thinking:{type:'adaptive',display:'summarized'}`）。

### 棠予酿（予予的日记/记忆库，MCP @ `https://mcp.nekopurrs.uk/mcp`）
- 它在用户 claude.ai 账号里是 **"claude.ai 连接器"**。**无头 `claude -p` 加载不到它**（已实测：`grep 棠予酿` ❌）。
- 手动 `claude mcp add --transport http ... mcp.nekopurrs.uk/mcp` → 状态 `! Needs authentication`（要 OAuth，无头/手机上认证很痛）。
- **结论：放弃实时 MCP**，改用**日记文件** `server/data/diary.md`：后端 `loadDiary()` 把它注入家版 CC 的人设，当长期记忆。文件不存在则跳过。代价：不自动同步，日记更新要手动覆盖该文件。

### 登录锁
- 前端 `AccessGate`（构建时设 `VITE_REQUIRE_ACCESS=1` 才启用）+ 后端 `APP_ACCESS_TOKEN` 校验 `x-app-token`。**目前未启用**（为先跑通家版）。注意：若只设后端 `APP_ACCESS_TOKEN` 而前端没带 token → 全 401。要开就两边一起开。
